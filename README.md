2. Stock Trading Platform

File: StockTradingPlatform.java

A console-based stock trading simulation that allows users to buy and sell shares using virtual money.

Features:

Display available stocks and simulated market prices.

Buy and sell shares.

Maintain a virtual cash balance.

View portfolio holdings.

Calculate average purchase price.

Track unrealized profit and loss.

Simulate stock price changes.

Concepts Used: Java, OOP, classes and objects, ArrayList, methods, loops, conditional statements.

Note: This is a simulated trading platform and does not use real-time stock market data or actual money.

3. Hotel Reservation System

Display available rooms.
